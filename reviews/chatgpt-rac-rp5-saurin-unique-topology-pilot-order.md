## E. Pelvis / sacrum / tail root

## F. Tail
- continuous with body;
- minimum 4 root rings;
- proposed 16-chain landmark architecture;
- evenly controllable rings along the tail;
- creator variation for base/length/mass/taper;
- LOD-friendly flow;
- tail tip exemption handled cleanly.

## G. Shoulders / arms
- deep thoracic shell / scapular organization;
- moderate arm contribution;
- modest forearm emphasis;
- adult elbow/wrist support.

## H. Hands / claws
- five digits;
- opposable thumb;
- moderately elongated fingers;
- fused claws/nails as accepted;
- 3 MCP / 2 IP support minimums;
- grasp-ready topology.

## I. Hips / legs

## J. Feet / claws
