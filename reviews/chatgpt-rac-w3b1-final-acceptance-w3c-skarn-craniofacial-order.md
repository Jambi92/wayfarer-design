# 8. REQUIRED RM-CF-09 METRIC SET

Define or reuse reproducible geometry metrics for the four required tendency families.

## 8.1 Skull size / robustness

Use a multivariate read, not one scalar.

At minimum report:

- head height / stature;
- cranial breadth / head height;
- cranial depth / head height;
- lower-cranial / jaw-support breadth where a stable landmark exists;
- a skull-volume or cranial-box proxy only if it can be measured reproducibly without inventing internal anatomy.

The phrase “suited to body size” means that raw head size must also be considered against stature / body scale.

Do not decide “Skarn have bigger skulls” merely because the Skarn comparator is taller.

## 8.2 Brow strength

Create a reproducible brow-prominence metric based on bony / structural geometry, such as:

- supraorbital projection relative to frontal plane / orbital rim;
- brow depth relative to cranial / orbital scale;
- a documented local plane / curvature proxy.

Do not use eyebrow hair.

Do not use expression.

Neutral expression is mandatory.

## 8.3 Jaw mass

Use structural measures that separate actual jaw architecture from facial fat / neck muscle.

At minimum include:

- bigonial / mandibular breadth normalized to head scale;
- mandibular depth / vertical body contribution;
- jaw angle / ramus support where reproducible;
- chin width only as a secondary diagnostic, because Skarn do not require a square chin.

Do not let high body fat masquerade as jaw mass.

Do not let high neck muscle become the jaw metric.

## 8.4 Midface / cheek substance

Use at minimum:

- bizygomatic / midface breadth;
- anterior midface projection;
- cheek / maxillary structural depth;
- nose size / projection as a secondary companion measure, not the whole midface tendency.

Keep soft-tissue fullness separate from skeletal midface structure where possible.
