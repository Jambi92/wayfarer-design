## 2. Core rule

For every OPEN item, classify it as one of:

**A — AUTHORABLE NOW:** existing positive anatomy, comparative rules and boundary tests support a qualitative or bounded biological decision without fabricated measurement.

**B — AUTHORABLE DIRECTIONALLY NOW / NUMERIC LATER:** biological relationship can be locked now, but numeric magnitude/envelope must come from reference-mesh measurement.

**C — REFERENCE-MESH DEPENDENT:** even the useful design answer requires approved mesh measurement; do not guess.

**D — LATER BIOLOGY:** real biological question not required to construct/validate the reference body now (e.g. reproduction, thermoregulation unless it changes visible anatomy).

**E — LATER SYSTEM / GAMEPLAY / EQUIPMENT:** not reference-anatomy closure.

Never convert C/D/E into A merely to reduce the OPEN list.

## 4. Existing GLB rule

The project already has race GLB assets produced through the image → Hyper3D → GLB pipeline. Treat those as **candidate reference geometry**, not automatically canonical measurement truth.

Do not derive canon numbers merely because a GLB contains them. First test each candidate against the canonical race spec. A mesh that violates approved anatomy must be corrected/replaced before it can supply measurement-derived canon.

Where an accepted GLB is adequate for a measurement, say so. Where it is not, specify the required reference variant semantically (e.g. central tendency, Narrow, Broad, min stature, max stature, creator extreme) without deciding UE5 topology or rigging.
