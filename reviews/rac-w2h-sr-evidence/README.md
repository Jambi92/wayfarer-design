# RAC W2H — Short-race family (Durrim / Pipkin / Cogling) evidence

NON-CANON diagnostics for `reviews/claude-rac-w2h-short-race-family-gate.md`.

- `w2h.json` — values and checks. Values are skin, skeletal proxy (t = 0 / 0.5 / 1) and exact-plane joint sections per stature and per adjacent segment, plus cranial proxies. Produced by `tools/rac/w1/w2h_drivers/w2h_eval.py` from `registry.json` (`w2h_reg.py`) and `spec.json` (`w2h_spec.py`).
- `construction.json` — every W2H body: the accepted references, the stature families, frames, composition states, named validators, DU-P4 composition bodies, the generator human-child proxies and the W1t DU-P4 pelvis-depth probes (NOT applied).
- `joint_sections.json` — exact-plane elbow / wrist / knee / ankle sections (`w2c1_drivers/joint_section.py`).
- `tables.md` — generated by `tools/rac/w1/gen_w2h_docs.py`.
- `sheets/` — render sheets (`w2h_drivers/render_AS_RUN.sh`). Each sheet uses one scale, so actual heights compare directly within a sheet.

Builders:
- `w2h_drivers/sr_build.py` — job sets stature / frames / comp / named / p4 / child.
- `w2h_drivers/p4_probe.py` — skeletal grids for the W1t DU-P4 probes.

Skeletal grids: `w2a_drivers/mfm_grid.py` per skeleton (`w2h_drivers/grids_AS_RUN.py`). Record: `tools/rac/w1/cfg/w2h/SR-family-boundary.json`.

Comparison rule: real matched height is used only where adult ranges overlap:
- Pipkin–Durrim at 122 cm;
- Cogling–Pipkin at 91 and 107 cm;
- Durrim–Marchfolk–Sagekin at 152 cm.

Every other comparison is a NORMALIZED ratio diagnostic against Marchfolk 173, or against its accepted W2A1 frames and W2A composition states. These are labelled as such and never treated as a same-height Marchfolk adult. Child proxies are generator human children, used as diagnostics only and never as a race baseline.
