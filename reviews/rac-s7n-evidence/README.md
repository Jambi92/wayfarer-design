# RAC S7 normalization evidence

For `reviews/claude-rac-s7-normalization-skarn-w2-final-gate.md` (author ruling `reviews/chatgpt-rac-w2b1-skarn-author-ruling-s7-normalization-order.md`).

- `normalized/` — the 20 S7-dependent evidence files re-run unchanged on S7-normalized skeletal-proxy inputs (same relative paths as under `reviews/`). These supersede the S7 values of the committed files, which stay as the historical record.
- `baseline_reproduction.txt` — the same 20 evaluations re-run on the old inputs reproduce the committed files exactly.
- `status_diff.json` — row-by-row result comparison (old committed vs normalized), with old / new values for every status change.
- `s7_values.json` — per skeletal-proxy body: old (vertex slab) and new (exact plane section) composition-infimum S7, t = 0 shares, change, control.
- `tables.md` — generated by `tools/rac/w1/gen_s7n_docs.py`.

Code: `tools/rac/w1/s7_station.py` (shared S7 reading, now `section`), `arm_measure.py`, `bony_envelope.py`; drivers `tools/rac/w1/s7n_drivers/` (`s7_normalize.py`, `remap_run.py`, `compare.py`, `status_diff.py`, `AS_RUN.sh`).
