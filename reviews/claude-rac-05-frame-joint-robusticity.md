**Author:** Claude

**Status:** PROPOSAL. Evidence: `reviews/rac-evidence/B-frame-joint-composition.md` Part 1.
**Feeds:** RM-UB-03, RM-LR-05, RM-SR-03. **No ratio is set.** Every equal-height and boundary test is preserved unchanged.

## 1. Universal rules already canon (carried)

- Frame = continuous skeletal breadth, depth, joint and robusticity configuration; write-and-vanish; never sex, body type, muscularity, fatness or stature (UCCA L119–L129).
- **Correlation ≠ dependency:** "Population correlations normally use weighted distributions/conditional probabilities/validity envelopes rather than hard creator dependencies" (PR L18); correlated dimensions stay independently editable where canon allows (UCCA L131; GR L330; GO L220).
- **Hard items stay hard:** joint hard minimums and each race's frame boundary rule (UCCA L131).

## 3. Proposed qualitative rules (class A)

| # | Rule | Basis |
|---|---|---|
| J-1 | **Universal joint floor:** for every race, joints are never implausibly tiny relative to the bones they connect, nor oversized as a cosmetic marker; a race's own hard-minimum wording, where stated, governs. Applies explicitly to MF, SK, SG, HV, SA, which state none | UCCA L131; FN L115; AE L130; VA L132 |
| J-2 | **Frame variable list pointer** for SK, SG, FN, HV: these races use the universal UCCA frame list (UCCA L119) inside their own envelopes | UCCA L119; no new biology |
| J-3 | **Absolute vs relative joint reading:** joint scale is assessed relative to the adjacent long-bone length **and** in absolute terms; a joint may be absolutely large and relatively lean (Grask) or absolutely small and relatively robust (Durrim) | GR L31, L217; DU L40; CG L743–747 decomposition |
| J-4 | **Robusticity ≠ muscularity:** bone shaft robusticity never follows muscle; low muscle never thins bone, high muscle never thickens it | CG L759–761; SA L339; DU L50 |
| J-5 | **Depth vs breadth independence:** thoracic depth and breadth are independent variables in every race; narrow never implies shallow | GO L222, L224; GR L38; UCCA L131 |
| J-6 | **Reference frame state:** ARMs carry population-central skeletal values (RAC-02 R-3), not "Balanced" as a default body | UCCA L121 |
