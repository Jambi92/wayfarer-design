# RAC W2E — Sagekin W2 evidence

NON-CANON diagnostics for `reviews/claude-rac-w2e-sagekin-boundary-gate.md`.

- `w2e.json` — values (skin, skeletal proxy t = 0 / 0.5 / 1, exact-plane joint sections per stature and per adjacent segment), checks (U C G O P K E F M X J D), accepted Sagekin W1 directional rows per body (`tools/rac/w1/w2e_drivers/w2e_eval.py` with `registry.json` from `w2e_reg.py` and `spec.json` from `w2e_spec.py`).
- `construction.json` — every W2E body: route, height macro or native factors, targets, frame bone scales, composition.
- `joint_sections.json` — exact-plane elbow / wrist / knee / ankle sections of the W2E bodies and the W1t 152 cm bodies (`w2c1_drivers/joint_section.py`); other comparators from the W2C1 evidence.
- `tables.md` — generated by `tools/rac/w1/gen_w2e_docs.py`.
- `sheets/` — render sheets (`w2e_drivers/render_AS_RUN.sh`).

Builder: `w2e_drivers/sg_build.py` (job sets stature / mf / named / sg04 / frames / comp); skeletal grids: `w2a_drivers/mfm_grid.py` per body. Record: `tools/rac/w1/cfg/w2e/SG-boundary.json`.
