# RAC W2G — Halvren central-envelope evidence

NON-CANON diagnostics for `reviews/claude-rac-w2g-halvren-boundary-gate.md`.

- `w2g.json` — values (skin, skeletal proxy t = 0 / 0.5 / 1, exact-plane joint sections per stature and per adjacent segment) and checks (U C G O A P X F M S K D). Produced by `tools/rac/w1/w2g_drivers/w2g_eval.py` from `registry.json` (`w2g_reg.py`) and `spec.json` (`w2g_spec.py`).
- `construction.json` — every W2G body and the probe: route, height macro or native factors, targets, bone scales, composition. It also records the two superseded expression builds (summed targets; max rule) with the reason each was replaced.
- `joint_sections.json` — exact-plane elbow / wrist / knee / ankle sections of every W2G body (`w2c1_drivers/joint_section.py`). Source-family sections come from the W2C1 / W2E / W2F evidence.
- `tables.md` — generated by `tools/rac/w1/gen_w2g_docs.py`.
- `sheets/` — render sheets (`w2g_drivers/render_AS_RUN.sh`).

Builders:
- `w2g_drivers/hv_build.py` — job sets stature / frames / expr / comp / stress.
- `w2g_drivers/aec_probe.py` — reading-bounded Aelari-influenced probe; NOT applied.

Skeletal grids: `w2a_drivers/mfm_grid.py` per body (`w2g_drivers/grids_AS_RUN.py`). Record: `tools/rac/w1/cfg/w2g/HV-boundary.json`.

Check codes:

| Code | What it checks |
|---|---|
| U | Allometry |
| C | Continuity of the central series |
| G | Accepted W1 rows at the fixed W1 references (REPORT under the boundary-stature rule) |
| O | Source-plausible spans at matched height |
| A | Axial / pelvic spans (REPORT) |
| P | Body-only source passing |
| X | Source-influenced expression |
| F | Frames |
| M | Composition |
| S | Stress combinations |
| K | Skarn guard (REPORT) |
| D | Route check (REPORT) |

Spans follow AD-G10: a reading outside the span by less than 1 % is MARGINAL; by 1 % or more it is FAIL.
