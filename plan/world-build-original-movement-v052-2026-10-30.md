# Wayfarer original movement restored in an isolated test version

October 30, 2026. At the user's request, the September-era Wayfarer project was inspected for its existing running, jumping, swimming and weapon movements. Its locomotion, swimming-aware movement, combat, inventory and water source files already match the current project's copies. A comparison also found 611 matching files across the original movement/combat animation, mannequin, animation blueprint and foley folders. This work reconnects those existing systems through the original Wayfarer character class.

Movement v052 is a separate copy of the current Aftermath v051 quest-study route. A new opt-in character adapter inherits the original character and retains its original Enhanced Input handlers, animation blueprint, locomotion component, swimming-aware movement component, combat and inventory. Existing cave collision dimensions are retained. Earlier maps, canonical geography, approved character bodies, rigs and source files are preserved. A separate neutral technical lab provides a controlled water basin and ground for movement verification; it is not a new area of the game world.

The restored controls include original walking/running/sprinting, stamina drain, jumping/landing, crouching, first/third-person camera, sword swings, guarding, bow draw/hold/release, crossbow aim/reload, real ammunition consumption, swimming strokes, diving, surface hold and physical wading onto the basin ramp. Temporary Vanguard, Lightkeeper and Oathsworn kits remain available. The test identity is chosen transiently, so the production character roster is neither opened nor saved. Class and gear fixtures do not grant campaign progress.

The original keys are remapped only where they conflict with the current quest study: **T draws/stows melee**, **F selects ranged stance**, **F4 changes camera**, and E / 1-4 remain story interactions. LMB swings or draws/releases/fires the equipped ranged weapon; RMB guards in melee or aims a ranged weapon. Shift sprints, Space jumps or rises in water, and Ctrl crouches or dives. F1 cycles the three class kits, F2 selects the level 1/5 fixture, F3 places a practice opponent, and F5 equips a temporary bow/crossbow kit. H/J/K/L retain the existing class-practice abilities. Class/gear fixture keys ignore Shift/Ctrl/Alt combinations, including Shift+F1 mouse release.

On the final native build, 69 checks pass across fresh movement, melee, bow, crossbow and swimming runs. Verification inspects actual animation clips and changing evaluated limb poses, real displacement, sprint stamina and one-round ammunition use. Swimming uses an explicit initial basin placement fixture, followed by physical entry, dive, stroke, surfacing and ramp exit. No cave water volumes or geography are changed by the lab test. Existing visual pools and streams still require their own depth/collision-aware integration before being described as swimmable.

A separate 33-check upper-return walk passes on the copied cave route with the restored character. That run begins with an explicit archive-exit fixture, then physically carries records through the approved return route, delegates the reachable rescue, observes the upper-exit figure and reaches the actual daylight assembly. Supported local saves round-trip and rewind coherently. This does not certify the earlier full first-contact sequence on this character, multiplayer, finished weapon art, final character rigging, first-time pacing or whole-Prologue completion.

Preservation verifies 2,654 original-project files and 149,676 prior protected world files, plus the prior current source/configuration/save snapshot. Only the two expected native module outputs are rebuilt. The copied level's map check has zero errors and warnings. A compressed E-drive checkpoint is verified by per-file hashes and archive readback. Public updates remain prose only; native assets, source, screenshots and diagnostics remain private.
